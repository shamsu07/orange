Install once. Keep it close.

The current download is for Apple silicon Macs running macOS 13 or later. You don’t need a compiler or separate conversion tools.

  1. Download the Orange disk image from the official GitHub release.
  2. Open the disk image, drag Orange into Applications, then eject the disk image.
  3. Open Orange from Applications. Review the launch-at-login option and choose Enable Orange.
  4. After setup, Orange lives in the menu bar. Open Settings there whenever you want to change something.

About the early release. The app is locally signed and is not notarized by Apple. macOS can block opening it. Only use a release you trust; review its checksums and source. Do not disable macOS security globally. You can also build from source.

Launch at login is optional. If macOS rejects registration or asks for approval in Login Items, setup can continue without it. Open Orange once to keep it available until your next login.

Try it with one image.

  1. In Finder, start dragging an image.
  2. While dragging, tap ⇧ Shift. The conversion wheel appears.
  3. Move the file over the wheel and release the mouse and key. The wheel stays open.
  4. Click a format. Orange creates a separate file next to your original.

You don’t need to hold the key or mouse while choosing. Hovering does not run an option. Press Esc to dismiss the wheel. If a name already exists, Orange adds a number instead of replacing the file.

Choose at your own pace. A sound and optional trackpad haptic mark the option under your pointer. Those are hover feedback, not a completed selection. Only a click runs the option.

The wheel adapts to the selection and available encoders. An extension alone does not guarantee a file can be decoded. Unsupported options stay out of the way. Large conversion menus use pages.

Keyboard selection and accessibility labels are available too. In Settings, you can assign a different modifier to each wheel.

Get an image just right.

Drag an image and tap ⌘ Command to see its tools. Available tools depend on the image format.

ToolWhat happens
ResizeChoose pixel dimensions. Preview the output dimensions and estimated encoded size before saving.
CropChoose an aspect ratio, move the selection or drag its corners. Fine adjustments are available for precision.
CompressFor JPEG and HEIC, lower encoding quality while keeping pixel dimensions. Review measured savings before saving.
RotateRotate the image and save a separate copy.
Text / QR / MetadataRecognize text locally, read QR content or remove selected metadata.

Resize changes dimensions. Compress changes encoding quality. A smaller image is not always a smaller file, and already efficient files can save little. Image compression rejects an unchanged or larger result. PNG does not have JPEG-style quality controls.

Size previews use temporary encodes. They are estimates, not a promised target. Animated and multipage images are not supported.

A PDF in the right pieces.

Use the tools wheel to split, merge or reduce a PDF. For a simple split, choose the page after which to divide it. For several parts, open custom ranges and set your groups. Each page must appear exactly once.

For size reduction, review the DPI, quality and estimated size. Saving is only enabled after you acknowledge what changes.

PDF reduction turns pages into images. It removes searchable text, vectors, links, forms, annotations, tags and signatures. Keep the original. Use this option for a smaller visual copy when losing those features is acceptable.

You can also export pages as images or extract text, with local OCR where needed. Text export does not reconstruct an editable Office document.

Find the moment worth keeping.

Drag a video and tap ⌘ Command for video tools.

  • Snapshot: scrub the timeline or type a time. Check the frame preview, then save that frame as an image.
  • Trim: adjust the start and end, review the selected duration, and play the range before saving.
  • Speed: choose a rate and review playback and the resulting duration.
  • Compress: choose quality settings. The finished result reports its actual size; media compression is not guaranteed to make every file smaller.

For multiple videos, timing controls are reviewed per file. Available audio tools include conversion, extraction, normalization and selected metadata removal. Variable-frame-rate timing preservation is not yet qualified for speed changes.

The everyday extras.

Use ⌃ Control for actions shared across file types. See Details, copy a file or its path, move it, open a floating shelf, share through AirDrop or open Terminal.

Terminal opens at the selected folder, or at the containing folder for a file. Move changes the source location; conversion and editing tools preserve the original.

Select several files to see Create ZIP. Items can come from different folders, but duplicate entry names are rejected. Orange creates archives; it does not extract them.

Keep the parts you use.

Open Orange Settings from its menu bar icon or by opening the app from Applications.

  • Choose Glass or Solid and set the wheel size. The default is 252 points; the minimum is 220. macOS Reduce Transparency uses an opaque surface.
  • Switch soft selection sounds and hover haptics on or off. Trackpad feedback is a system pattern; strength depends on the hardware.
  • In Menus, choose Command tools separately for images, video, audio and PDFs. Configure Control actions once for all files.
  • Shift conversions remain fixed and show the routes Orange can actually provide.
  • Set launch at login and whether finished files are revealed in Finder.

Keep Orange fresh.

Orange 0.1.5 and later can check for updates once a day. Turn automatic checks on or off in Settings. Background checks do not open a window or interrupt a drag.

  1. When a newer version is available, an Update button appears in Orange. You can also choose Check for Updates from the menu bar.
  2. Click to review the release and download it. Installation starts only after you choose to update.
  3. Orange verifies the signed update feed and downloaded archive. If work is still running, installation waits for it to finish before relaunching.

Checks contact GitHub Pages, and downloads come from the official GitHub Releases. They do not upload your files. Automatic checks can be disabled; manual checks remain available.

Coming from Orange 0.1.4 or earlier? Install the latest disk image once. Those versions do not include the updater. Future releases can then be installed from Orange.

The update signature verifies that the update was published with Orange’s release key. It does not replace Apple notarization; this early release is not notarized by Apple.

Something not behaving?

This is an early release. If a wheel does not open, confirm that Orange is running and Finder drag wheels are enabled in Settings. A fresh Finder drag is required; selecting a file and pressing a key by itself does not open the wheel.

For a bug report, include your macOS version, Orange version, file type and the exact steps that failed. Remove personal data before attaching an example. Report security concerns through the repository’s security policy.
