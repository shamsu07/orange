Orange 0.1.5 adds in-app updates and the public project website.

- Check for updates from the menu bar or the new Updates tab in Settings.
- Optional daily checks show an Update button without opening background windows.
- Review and install updates when ready. Orange verifies the feed and download with its update signing key and waits for active conversions and moves before relaunching.
- Open the product website for screenshots, downloads and a separate usage guide.
- Adds contribution, security and conduct guidance, complete Sparkle license notices, pinned dependencies and a maintainer release workflow.

Requires an Apple silicon Mac running macOS 13 or later. The download includes the media converters; no compiler or separate installation is needed.

This early release is ad hoc signed and is not notarized by Apple. macOS may block it. Orange 0.1.4 and earlier need one manual installation of this version to receive future in-app updates. Full Tangerine feature parity has not been established.
