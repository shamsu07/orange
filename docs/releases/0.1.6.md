Orange 0.1.6 fixes source-build compatibility with the Swift compiler on GitHub's macOS 15 runner by separating the PDF reduction screen into smaller views. The PDF controls and conversion behavior stay the same.

Includes the signed in-app updater, optional daily checks, product website and usage guide introduced in 0.1.5. Background checks do not open windows. Downloading and installation require your action.

Requires Apple silicon and macOS 13 or later. This early release is ad hoc signed and is not notarized by Apple. Versions through 0.1.4 need one manual installation of the latest download to enable future in-app updates. Full Tangerine feature parity has not been established.
